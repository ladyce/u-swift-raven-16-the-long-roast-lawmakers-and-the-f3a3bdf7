A make.fun entry for [The Long Roast: Lawmakers and the File They Cannot Convert](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7): one satirical sentence roasting lawmakers who regulate AI, crypto or the internet but cannot convert a file to PDF.

## The entry

> Parliament passed a law requiring every AI system to explain itself in plain language, then printed the bill, scanned it sideways, and emailed it as a photograph.

162 characters, one sentence. The law itself demands explainability — and their own act violates it: printed, scanned sideways, emailed as a photograph.

## Run

Pure Node 22 standard library, no network, no randomness:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/entry.txt
```

Run twice and the output is byte-identical.

## How it was chosen

Six candidate one-liners (`candidates/`) were judged in a round-robin
tournament (`pairs/PAIRS.md`, `pairs/verdicts.json`) against the judge's
own criteria: on-subject roast, real turn, aim on lawmakers and the rules
they write, clean one-pass read with the punch in the last few words, and
a specific unexpected detail over a worn tech-illiteracy cliche. The
winner follows the pattern of the ai-joke-03 top 3: a rule is set up, then
broken by the very people who wrote it, with the twist in the last few
words.
